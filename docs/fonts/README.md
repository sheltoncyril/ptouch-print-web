# Bundled fonts

Open-source typefaces offered in the web app's Font picker and by name in the CLI
(`--font oxanium | orbitron | jura | chakra-petch`). All are unmodified files from
[google/fonts](https://github.com/google/fonts) under the SIL Open Font License 1.1; each
family's licence and copyright notice is the matching `*-OFL.txt` here.

| Family       | Files                                        | Upstream                                  |
| ------------ | -------------------------------------------- | ----------------------------------------- |
| Oxanium      | `Oxanium[wght].ttf` (variable, 200–800)      | https://github.com/sevmeyer/oxanium       |
| Orbitron     | `Orbitron[wght].ttf` (variable, 400–900)     | https://github.com/theleagueof/orbitron   |
| Jura         | `Jura[wght].ttf` (variable, 300–700)         | https://github.com/ossobuffo/jura         |
| Chakra Petch | `ChakraPetch-Regular.ttf`, `-Bold.ttf`       | https://github.com/m4rc1e/Chakra-Petch    |
